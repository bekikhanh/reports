機能テスト 1  — 機能およびデータのリグレッションテスト

4.1 Functional Test (機能テスト)

  • ユーザーがトップページ、求人リスト、求人詳細画面を開けること。
  • エリア/路線・駅/職種/待遇/給与/キーワードで検索した際、条件を満たす求人のみが正しく返され、対象外の求人が表示されないこと。
  • ユーザーが検索条件を変更できること。
  • 必要な情報をすべて入力 → 確認 → 完了まで正常に遷移し、データがDBに保存され、メールがユーザー/店舗に正しく送信されること。
  • ユーザーが複数の求人に一括応募できること。
  • 応募の確認および完了ができること。
  • システムからユーザー/店舗へ正しいメールが送信されること。
  • ログイン後、マイページには現在ログインしているユーザーのデータのみが表示され、他ユーザーのデータが誤って表示されないこと。

4.2 Data Test (データテスト)

  • 求人情報が正しく表示されること。
  • 店舗情報が正しく表示されること。
  • 求人/店舗の画像が正しく表示されること。
  • 「承認済み」の求人ステータスが正しく表示されること。
  • 「掲載終了」および「公開継続」の求人ステータスが正しく表示されること。
  • 検索結果がフィルター条件と一致すること。
  • 応募データが正しく保存されること。
  • 応募した求人がマイページに正しく表示されること。

4.4 Regression Test (リグレッションテスト)

  • ホーム/検索結果から求人詳細へのリンクが正常に遷移すること。
  • 求人詳細/検索結果から応募フォームへのリンクが正常に遷移すること。
  • 確認画面で入力したデータが保持されていること。
  • 完了画面が正しく表示されること。
  • 応募メールが正常に送信されること。
  • ログイン後、マイページにログイン中ユーザーのデータのみが表示されること。
  • PC/スマートフォン上でレイアウトの大きな崩れが発生しないこと。
