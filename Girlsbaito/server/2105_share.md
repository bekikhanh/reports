====================================================
  ■ 報告事項①: 旧 laravel.log を経由した個人情報漏洩
  ====================================================

  ▼ 発見内容
  リニューアル時に、旧サーバ時代(XSERVER)の laravel.log
  (7.2GB、2022-10〜2025-06-24)が現サーバに引き継がれていた。
  nginx の設定不備(ドキュメントルートがプロジェクトルートを
  指していた)により、Web 経由でダウンロード可能な状態だった。

  ▼ 漏洩経緯
  - ファイル: /www/girls-baito-production/storage/logs/laravel.log
  - 状態: 5/20 時点で nginx 設定変更により遮断済み
  - ダウンロード総量: 474MB / 7.2GB (約6.6%)
  - 主要取得者: 212.86.126.157 (2026-04-05 に 367MB を取得、
    単発スキャナと判定、再アクセス無し)

  ▼ 漏洩した情報の内容
  Laravel が SQL 例外時にバインド値を含めて記録する仕様により、
  以下の情報がログに残存:
  - ユーザ of 氏名・メールアドレス
  - パスワードハッシュ(bcrypt)
  - 電話番号(一部)
  - アカウントステータス

  ▼ 影響対象(現用 DB と突合済み)
  合計 34 名 / 全 11,892 名中(0.29%)
    - 一般会員(role=1)        :  5 名
    - 店舗管理者(role=2)      : 28 名
    - 運営管理者(role=4)      :  1 名
    - テスト用アカウント       :  1 名(対応対象外)

  ▼ 漏洩したパスワードハッシュのリスク
  - bcrypt のため即時悪用は困難
  - ただし弱いパスワード(辞書攻撃で破られる類)はリスクあり
  - 漏洩ハッシュ = 現用ハッシュの可能性高い(対象ユーザの多くは
    漏洩後にパスワード変更していない)
